This project provides a robust, end-to-end Machine Learning pipeline for classifying tumors as **Malignant (M)** or **Benign (B)** using the **Breast Cancer Wisconsin Diagnostic Dataset**. It features a core benchmarking script using **Optuna** for hyperparameter tuning, an interactive **Streamlit Web Dashboard**, model explainability with **SHAP**, and a **FastAPI** backend to deploy the model as a REST API.

## ✨ Features

- **Model Benchmarking:** Compares Support Vector Machines (SVM) against Random Forest and Logistic Regression using `scikit-learn` Pipelines.
- **Advanced Hyperparameter Optimization:** Uses **Optuna** (Bayesian Optimization) for highly efficient, automated tuning of SVM parameters (C, gamma, kernel).
- **Interactive Web App:** A multi-tab Streamlit dashboard (`app.py`) for:
  - Real-time hyperparameter tuning.
  - Live prediction tool using feature sliders.
  - Model Explainability (Feature Importance & SHAP Summary Plots).
  - Custom dataset uploads for batch prediction.
- **REST API Deployment:** Includes `api.py` built with **FastAPI** to serve the best trained SVM model programmatically.
- **Advanced Visualizations:** Includes 2D PCA decision boundaries and a Seaborn-based Confusion Matrix.

## 🚀 Getting Started

### 1. Installation

Ensure you have Python installed, then install the necessary dependencies:

```bash
pip install -r requirements.txt
```

### 2. Running the Core Pipeline (Training)

Execute the main script to run benchmarking, tune hyperparameters via Optuna, and generate visualizations. This will also save `best_svm_model.pkl`:

```bash
python svm_breast_cancer.py
```

### 3. Running the Interactive Dashboard

Launch the Streamlit web application to explore the models, view SHAP plots, and run live predictions interactively:

```bash
streamlit run app.py
```

### 4. Running the FastAPI Backend

To expose your trained model as a REST API, run the FastAPI server:

```bash
uvicorn api:app --reload
```
Once running, you can access the interactive API documentation (Swagger UI) at `http://127.0.0.1:8000/docs`.

## 📊 Model Evaluation & Tuning

The `svm_breast_cancer.py` script automatically evaluates multiple algorithms and utilizes **Optuna** to find the absolute best parameters for the SVM. 

### ✅ Visual Output
The pipeline generates:
* `confusion_matrix.png`: To assess false positives and false negatives.
* `svm_linear_pca.png` / `svm_rbf_pca.png`: Decision boundaries based on Principal Component Analysis (PCA).
